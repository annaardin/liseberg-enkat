# Liseberg-enkät – Blomsterfonden

En enkel anonym webbenkät för boendeföreningen. Svaren är avsedda att skrivas till Google Sheet **Liseberg enkät – Blomsterfonden – svar**.

## Koppla svaren till Google Sheet

1. Öppna Google Sheet och välj **Tillägg → Apps Script**.
2. Ersätt innehållet i Code.gs med innehållet i `Code.gs` i detta repo.
3. Välj **Distribuera → Ny distribution → Webbapp**.
4. Kör som **Mig** och ge åtkomst till **Alla** som ska kunna svara.
5. Kopiera webbappens URL.
6. Ersätt `PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE` i `index.html` med URL:en.

## Publicera enkäten

Aktivera GitHub Pages för repots `main`-branch och rotkatalogen. Därefter kan enkäten delas via GitHub Pages-adressen.

Svaren innehåller ingen namn- eller e-postfråga.
